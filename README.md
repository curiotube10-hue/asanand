# Adhiraj Singh Anand — Mathematics Portfolio

The source for Adhiraj Singh Anand's mathematics portfolio, including research
writing, academic honors, a CV, and mathematical handouts.

Public site: [curiotube10-hue.github.io/asanand](https://curiotube10-hue.github.io/asanand/)

## Prerequisites

- Node.js `>=22.13.0`

## Run locally

```bash
npm install
npm run dev
npm run build
```

Pushes to `main` are published automatically through GitHub Pages.
