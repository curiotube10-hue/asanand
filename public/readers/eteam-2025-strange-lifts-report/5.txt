(c)  A = {1} ∪{P(n) | n ≥0}
We claim that dA(N) ≈0, or in other words, dA(N) is bounded above.
  Assume for the sake of contradiction there exists P such that dA(N) for A = {1} ∪{P(n) | n ≥0}
is unbounded.

  Eric Kamke proved in 1921[1] that if P(n) is a polynomial with no fixed divisor d > 1, then ∃s such
that
                             P(x1) + P(x2) + · · · + P(xt) = n
has a solution for large enough n and t < s.

  Say n is large enough is n ≥c for some constant c. For n < c, we have dA(n) ≤c −1 so dA(n) is
bounded above.

  Now, assume n ≥c.

  Case 1: d = 1

  Then, by the above theorem n can be represented in at most s steps, which is a contradiction.
