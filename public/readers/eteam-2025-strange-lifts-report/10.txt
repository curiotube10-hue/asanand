6  Set of Fibonacci numbers


  Question 6: Can you calculate or approximate dA for some other sets A? For example, for the
  set of Fibonacci numbers A = {1, 2, 3, 5, 8, 13, . . . }.

  Notice that we can replace 3fn with fn−2 + fn+2, 3f1 with 3 and 3f2 with f1 + f4, so we cannot
have more than 2 of each Fibonacci number.

  Say N = cnfn + cn−1fn−1 + · · · + c1f1, where ci ∈{0, 1, 2}.  If 2fn comes in the decomposition for
n ≥2, we can replace it with fn−2 + fn+1.

  Lastly, we can replace fn + fn−1 with fn+1. All of these operations either decrease or preserve the
number of times a lift is taken.

  So, we can rewrite this as the number of ways to write N with no consecutive Fibonacci numbers
and no number repeated.
