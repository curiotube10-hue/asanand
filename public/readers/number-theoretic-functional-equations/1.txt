  Example 1: Determine all functions f : Z →Z with the property that

                               f(x −f(y)) = f(f(x)) −f(y) −1

   holds for all x, y ∈Z.


Proof: y = f(x) =⇒f(x −f(f(x))) = −1

x = f(y) −1 =⇒f(−1) + 1 = f(f(f(x) −1)) −f(x) = f(f(x)) −f(x) = f(x + 1) −f(x)

So, f = mx + c, and matching coefficients,

m2 = m, 2mc = c + 1
